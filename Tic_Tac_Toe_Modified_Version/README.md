# 🎮 Tic Tac Toe: Modified Version 🚀

Welcome to the **Modified Version** of the classic Tic Tac Toe game! 🌟 This project features a robust **CLI (Command Line Interface)** implementation for the terminal and a high-fidelity **Web-based** version. 💻🌐

## ✨ Key Features 🚀

- **🕹️ CLI-Based Gameplay**: A powerful terminal experience with modern enhancements.
- **🤖 Single Player Mode**: Challenge an AI with three difficulty levels:
  - **🟢 Easy**: AI moves randomly. 🎲
  - **🟡 Medium**: AI tries to win and blocks your immediate threats. 🧠
  - **🔴 Hard**: AI uses the **Minimax Algorithm**, making it unbeatable! 🏆
- **👥 Multiplayer Mode**: Play with a friend locally on the same machine. 🤝
- **🎨 Improved Terminal UI**: Vibrant ANSI colors and a clear grid layout. 🌈
- **📊 Score Tracking**: Keep track of Wins, Losses, and Draws across your sessions. 📈
- **🛡️ Input Validation**: Prevents invalid moves and ensures a smooth experience. ✅
- **🌐 Web Version**: A premium, "gamified" web experience with smooth animations and modern design. ✨

## 🛠️ How to Run 🚀

### 💻 Terminal Version (CLI)
1. 📂 Navigate to this folder.
2. 🔨 Compile the code:
   ```bash
   gcc tictactoe_modified.c -o tictactoe
   ```
3. 🏃‍♂️ Run the executable:
   ```bash
   ./tictactoe
   ```

### 🌐 Web Version
1. 📁 Open `web/index.html` in any modern browser.
2. 🎮 Enjoy the gamified experience!
